# Contributing to Luna

Thank you for your interest in contributing to Luna!

## Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/atharhive/luna.git
   cd luna
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run local development server:**
   ```bash
   npm run dev
   ```

4. **Verify build before submitting:**
   ```bash
   npm run build
   ```

## Development Workflow

1. Fork the repo and create your branch from `main`:
   ```bash
   git checkout -b feature/my-feature
   ```
2. Make your changes and test locally at `http://localhost:5173`.
3. Keep commits clean, self-contained, and descriptive.
4. Ensure `npm run build` succeeds with zero errors.
5. Push to your fork and submit a Pull Request against `main`.

## Maintainer Responsiveness SLA
We aim to review and reply to every open issue and PR within **24 hours**.

## Code of Conduct
Please remain respectful, helpful, and constructive in all discussions, issues, and code reviews.
